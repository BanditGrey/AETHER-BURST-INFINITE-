# ⚔️ AETHER BURST: INFINITE

**Idle RPG com sistema de Burst e Resonance** — Unity 6

## Estrutura do Projeto

```
Assets/
├── Scripts/
│   ├── Core/                 # Enums + BaseStats
│   ├── Data/ScriptableObjects/   # Todos os dados do jogo
│   ├── Characters/           # CharacterRuntime
│   ├── Combat/               # Sistemas de combate
│   ├── Progression/          # Leveling, XP
│   ├── Economy/              # Shards, Reboot, Offline
│   ├── Managers/             # GameManager, SaveManager
│   └── Systems/              # BurstSystem, ResonanceSystem
├── Resources/
├── Prefabs/
├── Scenes/
│   ├── MainMenu.unity
│   ├── Combat.unity
│   └── Progression.unity
└── Art/
```

## Como começar

1. Abra a pasta no **Unity 2022.3+** ou **Unity 6**
2. Vá em `Assets/Scenes/MainMenu.unity`
3. Pressione Play

Todos os ScriptableObjects já estão configurados e prontos para uso.
